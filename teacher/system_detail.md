# System Details

## Session loop

1. Identify the current module and the next unresolved concept.
2. Ask one substantive Socratic question.
3. Diagnose the answer.
4. Push one level deeper with tradeoffs, math, or systems constraints.
5. End with a concise summary and next action.

## Update policy

- Update `progress.md` after each meaningful session.
- During long sessions, checkpoint `progress.md` and `session_archive.md` whenever a stage/module is marked complete or a handoff is accepted.
- Add durable weak spots to `interview_bank.md`.
- Add textbook or resource issues to `book_revision_notes.md`.
- Keep `teaching_modes.md` short and reusable.
- Use `exam_blueprint.md` for milestone checks instead of inventing a new exam each time.
- Move stale details into `session_archive.md`.
