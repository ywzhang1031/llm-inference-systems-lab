# Exam Blueprint

## Weekly check

- Explain one latency or throughput metric without notes
- Debug one measurement or workload error
- Defend one systems tradeoff using evidence

## Milestone checks

- Metrics: reconstruct TTFT, TPOT, E2E, and percentile calculations from raw events
- Baseline: reproduce a vLLM result from a clean environment and raw workload
- Comparison: explain a vLLM/SGLang difference without overclaiming causality
- Final: defend the benchmark methodology, profiler evidence, and one source-level finding
